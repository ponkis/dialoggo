# Support

For a reproducible bug or a feature proposal, use the matching issue form in the repository. Before opening an issue, check whether a similar report already exists.

For a bug report, include:

- Dialoggo version and operating system
- What you expected and what happened
- Steps that reproduce the problem
- Relevant error text, with usernames, personal paths, and other private information removed
- The log file, if available: `%APPDATA%\Dialoggo\logs\dialoggo.log` on Windows, `~/Library/Application Support/Dialoggo/logs/dialoggo.log` on macOS, or `~/.config/Dialoggo/logs/dialoggo.log` on Linux

For setup and contribution steps, see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Do not use public issues for suspected security vulnerabilities; follow [SECURITY.md](SECURITY.md) instead.
